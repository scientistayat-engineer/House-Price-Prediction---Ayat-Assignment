# House Price Prediction - End-to-End Machine Learning

### 🚀 Project Overview
This project predicts house prices based on various features like location, area, and number of rooms using Regression algorithms. Developed as part of my Data Science training at SMIT.

### 📊 Dataset
The dataset includes features such as:
*   **Age**: Construction age of the house.
*   **EstimatedSalary**: Socio-economic indicator of the area.
*   **Price**: Target variable (House Price).

### 🛠️ Tech Stack
*   **Language**: Python
*   **Libraries**: Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib
*   **Environment**: Google Colab

### 📈 Model Performance
We compared three different regression models. The results are based on the **R² Score**:
*   **Linear Regression**: 0.86 (Approx)
*   **Decision Tree**: 0.78
*   **Random Forest**: 0.84 (Best Performer)

### 📁 Structure
*   `House_Price_Prediction.ipynb`: Main project notebook.
*   `dataset.csv`: House price data.
