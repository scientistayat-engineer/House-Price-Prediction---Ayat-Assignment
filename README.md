# House Price Prediction - End-to-End Machine Learning

### 🚀 Project Overview
This project predicts house prices based on various features like location, area, and number of rooms using Regression algorithms. Developed as part of my Data Science training at SMIT.

### 📊 Dataset
The dataset includes features such as:
*   **Age**: Construction age of the house.
*   **EstimatedSalary**: Socio-economic indicator of the area.
*   **Price**: Target variable (House Price).

### 🛠️ Tech Stack
*   **Language**: Python
*   **Libraries**: Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib
*   **Environment**: Google Colab

### 📈 Model Performance
We compared three different regression models. The results are based on the **R² Score**:
*   **Linear Regression**: 0.86 (Approx)
*   **Decision Tree**: 0.78
*   **Random Forest**: 0.84 (Best Performer)

### 📁 Structure
*   `House_Price_Prediction.ipynb`: Main project notebook.
*   `dataset.csv`: House price data.
*   `README.md`: Project documentation.

## **📝 Project Overview**
This project is an end-to-end Machine Learning solution designed to predict **House Prices** based on key features like location, area, and property age. As an AI and Data Science student at Saylani Mass IT Training (SMIT), I developed this project to apply regression techniques to real-world datasets, specifically focusing on data collected from House Price Prediction.

### **🎯 Objective**
The main goal is to build a high-performance model that can estimate property values with precision, helping potential buyers and sellers make data-driven decisions.

### **🛠️ Methodology**
1. **Data Exploration (EDA)**: Understanding the relationship between house age, location, and price.

2. **Data Preprocessing**: Handling missing values and applying **StandardScaler** to normalize the features.

3. **Model Selection**: Comparing multiple algorithms to find the best fit for numerical prediction.

4. **Evaluation**: Using the **R² Score** to measure how well the models explain the variance in house prices.
